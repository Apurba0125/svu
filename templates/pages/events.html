WHAT THIS PAGE IS Four tabs, each holding the same photograph grid used on library.html and the other Life at SVU pages. Nothing here is new machinery: the tab pills and the mobile dropdown come from department.css and main.js, the grid and the click-to-enlarge viewer from gallery.css, base.css and main.js. Only events.css is specific to this page, and it exists for one reason — see the note on AOS below. TO ADD A TAB Two things that reference the same id: 1. a list item + button in .dept-tab-nav data-bs-target="#eventpane-X" 2. a .tab-pane below id="eventpane-X" Exactly one button carries "active" and one pane carries "show active", and they must be the same tab. The mobile dropdown builds itself from that same list, so there is nothing extra to keep in step. HOW THE VIEWER IS WIRED data-viewer on a grid makes it one gallery; data-viewer-item on each cell makes it a frame. Each grid is its own gallery, so the arrows and the counter stay inside the tab you opened rather than walking the visitor into a hidden pane. main.js groups by the container ELEMENT, not by the name, so the name is a label for whoever reads the markup next — keep it matching the tab anyway, because two grids both called "seminars" read as a bug even when they behave correctly. The caption under an enlarged photograph is that image's own alt text, so writing a good alt does double duty. Clicks work from a hidden pane too — the handlers are bound to elements, not to what is currently visible. WHY events.css EXISTS INSTEAD OF data-aos AOS measures every element once at page load. Anything inside a display:none tab pane measures zero, so AOS treats it as already scrolled past and fires it while still hidden; open the tab later and the cells simply appear with no animation at all. events.css does the reveal from CSS keyed off .tab-pane.active, which also means it replays each time a tab is opened. Do not put data-aos on anything inside a pane. TO ADD A PHOTOGRAPH 1. Put the file in static/img/Events/ 2. Copy one "gallery cell" block into the right tab and change the src and the alt 3. Run: python manage.py collectstatic --noinput Not optional — a static path with no manifest entry raises ValueError on every request, so the page goes down rather than showing a broken image. Cells are a fixed height and the photograph is cropped to fill, so portrait, landscape and square originals all come out identical in the grid. The enlarged view shows the whole uncropped photograph. Rows are four across, so a count that is a multiple of four never leaves an orphan tile. WRITE THE ALT FROM THE PHOTOGRAPH IN FRONT OF YOU. Copying the line above it and leaving the words alone is the one mistake that actually reaches visitors: the alt is also the caption under the enlarged image, so a wrong one is not a silent accessibility slip, it is visibly incorrect text on the page. Every caption on this page is unique; keep it that way. !!
