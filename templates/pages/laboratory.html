Swap the title, the copy and the photographs; nothing else needs wiring. HOW THE VIEWER IS WIRED data-viewer on the grid makes it one gallery; data-viewer-item on each cell makes it a frame. That is the whole contract — no onclick attributes and no index numbers to keep in step, so inserting a photograph in the middle does not renumber anything after it. The viewer (counter, fullscreen, close, arrows, caption, keyboard, swipe) is built by main.js and styled in base.css, shared by every gallery page. The caption under the enlarged photograph is the image's own alt text, so writing a good alt does double duty and there is no second list of titles to fall out of sync with the images. TO ADD A PHOTOGRAPH 1. Put the file in static/img/laboratory/ 2. Copy one "gallery cell" block and change the src and the alt 3. Run: python manage.py collectstatic --noinput Not optional — a static path with no manifest entry raises ValueError on every request, so the page goes down rather than showing a broken image. Cells are a fixed height and the photograph is cropped to fill, so portrait, landscape and square originals all come out identical in the grid. The enlarged view shows the whole uncropped photograph. The repository only has the two laboratory photographs the homepage already uses, so the grid is seeded with those and they still live in static/img/. Put new ones in static/img/laboratory/ and move these two across when you have a moment — the homepage tile in CAMPUS_GALLERY_ITEMS points at them.
